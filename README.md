# ML-IDS-LLM

A pipeline that trains a lightweight detector on network flow data, extracts
statistically suspicious patterns, and uses an LLM to generate validated
Suricata rules.

## Status

Phase 0 — project scaffolding.

## Layout

| Folder | Purpose |
|---|---|
| data/ | dataset copy (not committed) |
| src/ | Python code |
| rules/ | generated Suricata rules |
| prompts/ | prompt templates |
| config/ | settings |
| logs/ | audit trail (not committed) |
| notebooks/ | exploration |
| docs/ | drawing and report material |
